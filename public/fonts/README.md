# Nibmark Hangul fonts

Derived from Noto Sans KR (SIL Open Font License 1.1):
https://github.com/google/fonts/tree/main/ofl/notosanskr

Static instances at weights 400 and 700, subset for Hangul syllables/jamo,
Latin, punctuation and mathematical symbols, renamed Nibmark Hangul.
Prepared with fontTools 4.68.0. See OFL-NotoSansKR.txt.
The files are loaded locally only when Korean or fallback glyphs are needed.
